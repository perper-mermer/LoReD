## Frozen scope

1. **Sensitivity only on the 499 development responses.** No RAGTruth test or HaluBench metrics are computed for parameter variants. One-factor-at-a-time grid: C in {0.01,0.03,0.1,0.3,1.0} at run cutoff rho=0.5; rho in {0.3,0.4,0.5,0.6,0.7} at C=0.1. The central configuration is shared, giving nine unique configurations. Report every configuration, without selecting a winner or replacing the main model.
2. **Nested development analysis.** Preserve lexicographic ID order, support=1 labels, StandardScaler and balanced L2 LR(lbfgs, max_iter4000). Use fixed outer StratifiedGroupKFold(5), seed20261010; inner4 grouped folds, seed20261010+outer_index+1. Use historical threshold candidates linspace(.1,.9,81), hallucination F1 first, then Macro-F1/BAcc/accuracy/proximity to .5. Fit scaler/model only on each inner training partition. Select a threshold within each outer training partition, fit the outer model with seed20261010+500+outer_index, and predict its outer validation partition. Pool the five outer-validation decisions for the reported nested-development metrics. These are diagnostic results on repeatedly used development data, not a new independent test. No final parameter choice is made from this grid.
3. **Positive-case rule.** From canonical frozen RAGTruth predictions, consider hallucinated responses correctly detected by LoReD but missed by Fixed-Max, in ascending numeric response-ID order. Inspect at most the first20. Select the first whose raw source, response and annotated span permit a clear evidence-grounded explanation; record exclusion reasons if earlier candidates are not usable. If none is usable, use the first clearly verifiable hallucination detected by both methods and label that fact. Match source/response IDs, source task, test split, raw annotations and prepared sentence-risk order. A single illustrative case is not an independent relabeling study or a frequency estimate. Existing supported cases remain reported.
4. **Current-machine timing only.** Load the already frozen models for Fixed-Max, Calibrated-Max, StatLR-2, StatLR-4 and canonical LoReD. No training or threshold selection. Incoming NumPy sentence-risk arrays are preloaded. Time feature computation, StandardScaler/classifier prediction where applicable, and binary threshold decision, excluding loading, sentence verification and feature-dispatch bookkeeping. Warm up200 responses, repeat10 times for each of2700 responses, disable Python GC in the timed region, restrict BLAS to one thread and interleave five methods in a predetermined cyclic order over repeats. Record actual CPU model, core counts, RAM, OS, Python/packages, threadpool information and thread environment. Summary: median/P95 across per-response medians and throughput from their arithmetic mean. Preserve original114.90/237.95us records separately. The new timing run cannot retroactively establish the old hardware environment.
